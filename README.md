# Projeto de Estudo: Calculadora em Java Swing

Este projeto consiste em uma **calculadora gráfica desenvolvida com Java e Swing**, com o objetivo principal de aprimorar conhecimentos em desenvolvimento de interfaces gráficas e consolidar práticas com a linguagem Java e o uso do Git.

## Objetivos do Projeto

- Praticar os fundamentos da linguagem Java em uma aplicação visual.
- Explorar o uso da biblioteca **Swing** para construção de interfaces gráficas.
- Exercitar a organização do código em um projeto simples e funcional.
- Aplicar conceitos de versionamento com Git durante o desenvolvimento.
- Trabalhar o aspecto visual da aplicação, utilizando uma **paleta com tons de azul** para a interface.

## Funcionalidades

- Operações básicas: adição, subtração, multiplicação e divisão.
- Interface simples e responsiva.
- Layout com cores agradáveis e foco na usabilidade.

## Tecnologias Utilizadas

- Java (versão utilizada no desenvolvimento)
- Java Swing (GUI)

## Observações

Este projeto foi desenvolvido com fins educacionais, como parte do processo de aprendizado contínuo em Java. Futuras melhorias e funcionalidades adicionais estão previstas para versões posteriores.
